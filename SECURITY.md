# Security

Pidge is experimental. Use test accounts, review action approvals, and keep
provider spending limits low. The latest experimental source is the supported
version; there is no security response-time commitment.

Report vulnerabilities privately to [security@composio.dev](mailto:security@composio.dev),
Composio's [published security contact](https://github.com/ComposioHQ/composio/security).
Use a subject beginning with "Pidge security" and include the affected commit,
impact, and a minimal reproduction using accounts you own.

Do not post secrets, personal messages, working authentication links, or exploit
details in public issues. Redact credentials from attachments. Test only your
own isolated deployment; do not probe another operator's service.
